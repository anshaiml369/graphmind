Graph neural networks · transductive node classification

Classifying research papers by topic from their citation graph

Each node is a paper described only by binary word-presence indicators; each edge is a citation. A two-layer graph convolutional network (GCN) predicts one of seven topics by combining a paper's own words with those of the papers it cites or is cited by. This workspace runs the exported ONNX model live and lets you inspect what the graph contributes.

      Limitations and research notes

      1. Single run. All recorded numbers come from one training run with no fixed PyTorch seed; no mean ± standard deviation over seeds is reported, so small differences between models should not be over-interpreted.
      2. Exported weights are the final-epoch weights. The notebook stores best_state = model.state_dict(), which keeps references to the live parameters rather than a copy. The restored model is therefore the epoch-35 model: its validation accuracy measured here is lower than the logged best (0.812).
      3. Overfitting to 140 labels. Training accuracy is 1.000 while validation and test accuracy are ≈0.79.
      4. Transductive setting. Test papers' features and citation edges are visible at inference time (standard for Planetoid). The model cannot classify a genuinely new paper without adding it to the graph.
      5. No raw text. Cora in PyTorch Geometric ships only binary indicators over an undistributed 1,433-word vocabulary, so this interface cannot show titles or words, and free-text input is not possible.
      6. Baseline description mismatch. The notebook's text says the Random Forest also uses degree and log-degree features, but the code trains on the TF-IDF-reweighted word features only.
      7. Correlation, not causation. Better accuracy with edges indicates topical homophily in the citation graph; it does not show that citations determine topics.
